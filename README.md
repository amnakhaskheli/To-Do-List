To-Do List Web Application 📝

A simple and user-friendly To-Do List web application developed as my first JavaScript project during the 4th semester of my BS Information Technology degree.

This project helped me practice JavaScript fundamentals and understand how HTML, CSS, and JavaScript work together to create an interactive web application.


✨ Features

- Add Tasks: Add new tasks to your list.
- Delete Tasks: Remove individual tasks.
- Clear All: Clear all tasks from the list.
- Simple UI: A clean interface with a soft green color theme.


🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript

🚀 How to Run

1. Clone or download this repository.
2. Open the project folder in VS Code.
3. Open "index.html" in your browser.
4. Start adding tasks to your list.
